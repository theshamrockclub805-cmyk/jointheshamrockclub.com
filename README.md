# Shamrock Club Landing Page

A single-page landing site for the Shamrock Club sponsorship program. Businesses can learn about membership tiers, view program impact, and submit an inquiry to join.

## Live Site

Hosted via [Netlify](https://www.netlify.com/), deployed automatically from this repository.

## Structure

This is a static site — a single `index.html` file with embedded images and inline CSS/JS. No build step is required.

- `index.html` — the full landing page (hero, impact gallery, how it works, pricing, corporate sponsorships, benefits, inquiry form, FAQ, footer)

## Deployment

This repo is connected to Netlify:

1. Push changes to the `main` branch (or edit `index.html` directly on GitHub).
2. Netlify automatically detects the change and redeploys the site — no manual build or publish step needed.

**Build settings on Netlify:**
- Build command: *(none)*
- Publish directory: `/`

## Updating Content

To update copy, images, or sections:

1. Edit `index.html` (locally or directly in the GitHub web editor).
2. Commit the change.
3. Netlify will redeploy within seconds — refresh the live site to see it.
